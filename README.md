## KVM、OpenVZ、LXC 差在哪，为什么优先选 KVM

KVM 是完整虚拟化：每台 VPS 是一台独立虚拟机，有自己的内核，CPU、内存、存储都是隔离分配的。OpenVZ 和 LXC 本质上是容器，多个用户共享宿主机的内核。国内老牌 VPS 资讯站给新人的建议排序一直是 KVM 优先、Xen 次之、OpenVZ 最后，价格也大体按这个顺序从高到低。

不跑容器的话，KVM 的好处主要是资源隔离带来的稳定——邻居吃满 CPU，不容易直接拖垮你的磁盘 IO 和内存带宽。

要跑 Docker 的话，KVM 基本是必选项，这一点很多推荐文章没讲透。OpenVZ 和共享 LXC 的"VPS"本身就是容器，Docker 跑在里面等于容器套容器：内核模块加载不了，存储驱动经常退回慢速的 vfs 模式，自定义 iptables 规则、overlay 网络、`--cap-add` 这类特权操作也常被宿主机拦下。WireGuard 容器、NFS 挂载、自定义 seccomp 配置、嵌套虚拟化，这些直接碰内核的东西在容器型 VPS 上大概率跑不通。KVM 没有这层天花板，Docker 的行为和在独立服务器上一致。

## KVM VPS 常见问题

### 怎么确认买到的是真 KVM？

登录服务器跑一条命令就够：`systemd-detect-virt`，返回 `kvm` 就是 KVM，返回 `openvz` 或 `lxc` 就是容器。老系统可以用 `virt-what`。下单前产品页没标虚拟化类型的，直接问客服要一句明确答复。

### KVM VPS 能跑 Docker 吗？

能，而且 KVM 是跑 Docker 最省心的类型：独立内核意味着 overlay2 存储驱动、iptables、内核模块加载这些 Docker 依赖的能力都正常可用。

### 年付和月付怎么选？

确定要跑一年以上的项目选年付，RackNerd 年付 $21.99 折合每月不到 2 美元，比月付划算得多。不确定的项目一律月付：Contabo 有 14 天退款，Vultr 按时计费随开随删，试错成本低。

### 为什么同配置的 KVM VPS 价格差好几倍？

通常差在三个地方：回国线路、IP 类型、商家超售的比例。DMIT 1核1G 卖 $6.90/月，RackNerd 同配置年付只要 $21.99，差价主要在线路；LisaHost 的住宅 IP 机型贵在 IP 成本。比价之前先看这三样，再看 CPU 和内存。
